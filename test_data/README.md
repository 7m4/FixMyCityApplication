# Test data

هذه الملفات تحتوي على بيانات JSON محلية لتجربة الواجهات فقط، وليست بيانات حقيقية ولا تتصل بخادم أو قاعدة بيانات.

## الملفات

- `reports.json`: مجموعة صغيرة من البلاغات لاختبار العرض المعتاد.
- `large_reports.json`: قائمة أطول لاختبار التمرير وارتفاع البطاقات والنصوص المختلفة.
- `empty_reports.json`: قائمة فارغة لاختبار حالة عدم وجود بلاغات.
- `notifications.json`: إشعارات بحالات مقروء وغير مقروء.
- `categories.json`: فئات البلاغات والأقسام المرتبطة بها.

## طريقة الاستخدام

تُحمّل الملفات من خلال `TestDataLoader` الموجود في `lib/core/testing/`. عند ربط التطبيق بالـ API لاحقاً، نستبدل مصدر البيانات في طبقة البيانات، ولا نضع قراءة JSON داخل ملفات الشاشات.

> لا تستخدم هذه البيانات في بيئة الإنتاج.
